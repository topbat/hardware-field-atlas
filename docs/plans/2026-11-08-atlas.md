# 硬件志实施计划

**目标** 交付以国内 AI 硬件为主的研究平台，覆盖目录、部件溯源、交互式结构及研究工作流。

**架构** React 同源访问 FastAPI。目录采用版本化 JSON 种子和 SQLite 持久覆盖。研究工作区按浏览器随机凭证隔离。Blender 按部件导出 GLB，并复用目录部件 ID。

1. 比较拆解、开源设计、3D 浏览和工作流工具，确认目录、拆解台、研究室三层设计。结果见 docs/research-*.md。
2. 依据 docs/api.md 建立目录检索、对比、BOM CSV、纠错和修订接口，验证来源关联与写入权限。
3. 研究室实现范围选择、证据筛选、答案和引用，显示运行模式，验证隔离、记忆同意和模型降级。
4. 实现响应式目录、档案、对比和研究室，验证关键浏览器路径。
5. 生成三套研究模型与可编辑源件，核对模型节点和目录部件。
6. 验证安装、构建和生产运行入口，提供持久卷和部署配置。
